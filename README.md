# 电子斗蛐蛐 · QuQuBattleGame

Windows 桌面宠物养成 + 蛐蛐对战游戏。蛐蛐常驻桌面最上层，打字、点鼠标都会给它涨经验，
目前已支持属性装备、桌面副本、竞技场对战和六品种手绘美术。

详细版本路线见 **[ROADMAP.html](ROADMAP.html)**。

## 操作

| 操作 | 效果 |
|---|---|
| 按住蛐蛐拖动 | 拖到屏幕任意位置，松手自动吸附回屏幕内 |
| 打字 | 每个按键 +1 经验 |
| 鼠标左键点击 | 每次 +2 经验 |
| **右键蛐蛐** | 功能菜单：蛐蛐装备 / 副本 / 蛐蛐设置 / 退出游戏 |
| 托盘图标右键 | 同上（蛐蛐被拖丢时的退路） |

### 蛐蛐设置

| 项 | 说明 |
|---|---|
| 蛐蛐大小 | 60% ~ 200%，拖动即时预览，松手记住 |
| 显示经验条 | 关掉后桌面只剩蛐蛐本体 |
| 始终显示在最前 | 关掉后会被其他窗口盖住 |
| 蛐蛐品种 | 临时入口，切换后外观和属性一起变（后续改为孵化/捕捉获得） |

设置存在 `data/settings.json`，与存档分开——重置蛐蛐不会清掉外观偏好。

经验需求与等级上限读取成长表（当前上限 80 级）。品种、等级与位置存在 `save.json`，关掉再开接着长。

## 数值表（配置驱动）

**游戏配置以 `数值表/QuQu数值表.xlsx` 为准；代码保留缺失配置的兜底值。**
改表 → 保存 → 重启桌宠即生效（启动时自动检测 Excel 是否比 JSON 新，是则重新导出）。

| Sheet | 用途 |
|---|---|
| 0-说明 | 使用说明与约定 |
| 1-属性定义 | 属性清单、取值范围、是否战斗可见 |
| 2-品种 | 6 个品种的基础属性 + **主色（直接决定蛐蛐配色）** |
| 3-成长 | 每级的属性增量与升级经验，行数决定成长上限 |
| 4-招式 | 伤害系数、耐力消耗、命中暴击修正、附带状态 |
| 5-克制 | 招式之间的克制矩阵（剪刀石头布） |
| 6-状态 | 力竭 / 流血 / 破防 / 士气高涨 等 |
| 7-战斗常数 | 护甲系数、力竭时长、士气阈值等全局公式参数 |
| 8-天赋 | 随机词条与效果 |

手动重新导出：`python 导出数值表.py`（产物 `data/stats.json`）

> 想加新属性：先在「1-属性定义」登记，再到「2-品种」加列，最后在 `stats.py` 的
> `SPECIES_COL` 映射里补一行。表头名字不要改，ID 不要改。

## 设计要点

**不干扰正常使用电脑**：窗口设了 `WA_TransparentForMouseEvents`，鼠标点击会穿透蛐蛐落到下层窗口。
拖动不走 Qt 事件，而是用全局钩子（pynput）判断"按下点是否落在蛐蛐身上"，
再在 60fps 定时器里读 `QCursor.pos()` 移动窗口。

**蛐蛐使用分层美术**：`cricket.py` 管动画，`cricket_art.py` 绘制身体与肢体，
`art_assets.py` 加载 `assets/art/manifest.json` 指定的贴图。打包必须包含 `assets/art/`。

**动画**：呼吸缩放、随机眨眼、每 4~12 秒随机蹦跶/鸣叫/转身；跳跃是真实抛物线物理
（初速 620 重力）；鸣叫时翅膀掀起并高频抖动；吃经验会小幅兴奋。
