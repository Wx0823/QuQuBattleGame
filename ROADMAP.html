各版本需求明细

v0.1已交付
桌宠挂机基础
让蛐蛐先"活"在桌面上，验证桌宠形态与挂机手感。
  • 透明置顶窗口，鼠标穿透不挡正常操作
  • 蛐蛐形象纯 QPainter 手绘，无外部素材
  • 挂机动画：呼吸、眨眼、随机蹦跶 / 鸣叫 / 转身
  • 可拖动到屏幕任意位置，松手自动吸附回屏内
  • 打字 +1 经验、鼠标点击 +2 经验
  • 等级经验条 + 升级光环与飘字
  • 本地存档 save.json，托盘菜单退出 / 重置
v0.2下一版
属性与状态
给蛐蛐加"数值"，并引入需要维护的状态，为喂食和战斗铺路。
  • 四维属性：攻击 / 防御 / 速度 / 体力，由等级与天赋派生
  • 三条状态：饱食度 / 心情 / 体力，随时间自然衰减
  • 属性面板：右键或悬浮查看数值明细
  • 状态影响成长：心情 ≥80 时经验获取 +20%，饥饿时衰减
  • 存档结构升级，兼容旧档（缺字段自动补默认值）
v0.3待开始
喂食与训练
让玩家有事可做，把"挂机涨经验"变成"主动养蛐蛐"。
  • 食物道具：毛毛虫 / 豆类 / 露水，分品质与效果
  • 喂食动画与饱食度、心情回复
  • 训练小互动：连点 / 节奏点击，提升指定属性
  • 体力消耗与随时间恢复，防止无限刷
  • 经验可作为通用货币购买食物
v0.4待开始
斗蛐蛐对战 核心玩法
项目名字里的"斗"，玩法真正成立的一版。
  • 战斗数值：伤害 = 攻击 × 系数 − 防御，速度决定出手顺序
  • 回合制自动战斗，带暴击与闪避随机性
  • 对手梯度：野虫 / 同级 / 精英，按等级解锁
  • 战斗表现：冲撞、鸣叫威慑、退避，伤害飘字与血条
  • 胜负结算：经验、道具、连胜计数
  • 战斗加速与跳过
战斗窗口形态待定：是在蛐蛐旁边弹一个小战场，还是单独开一个窗口。 倾向小战场贴着蛐蛐弹出，保持桌宠感。
v0.5待开始
擂台与天赋
给长期玩提供目标和随机性。
  • 天梯擂台：连胜榜、排名、每日挑战次数
  • 天赋词条：随机 1~3 条，影响战斗风格（如"越战越勇""铁壳"）
  • 装备 / 信物：小幅加成，可掉落
  • 赛季重置与段位
v0.6待开始
收集与图鉴
从"一只蛐蛐"扩展到"一群蛐蛐"。
  • 捕捉 / 孵化获得新蛐蛐
  • 品种差异：外观配色 + 属性倾向（如"铁头"偏防、"疾风"偏速）
  • 图鉴收集度与解锁奖励
  • 多蛐蛐管理，切换出战
v1.0待开始
完整版打磨
能拿给别人用的状态。
  • 音效：鸣叫、进食、战斗、升级
  • 设置面板：开机自启、缩放、透明度、音量、开关经验提示
  • PyInstaller 打包单文件 exe

事项说明
战斗窗口形态 小战场贴蛐蛐弹出 vs 独立窗口，v0.4 前需定夺
蛐蛐美术风格 当前为萌系圆滚卡通，若改写实斗虫风只需改 cricket.py
数值平衡 挂机涨经验速度偏快（打字即涨），v0.2 引入状态后需重新配平
全局钩子权限 pynput 在管理员权限程序中可能收不到按键，属系统限制
注意：v0.2 起存档结构会变，必须写兼容逻辑读取旧 save.json， 否则老档会直接崩。
