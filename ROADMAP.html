各版本需求明细

v0.1已交付
桌宠挂机基础
让蛐蛐先"活"在桌面上，验证桌宠形态与挂机手感。
  • 透明置顶窗口，鼠标穿透不挡正常操作
  • 蛐蛐形象纯 QPainter 手绘，无外部素材
  • 挂机动画：呼吸、眨眼、随机蹦跶 / 鸣叫 / 转身
  • 可拖动到屏幕任意位置，松手自动吸附回屏内
  • 打字 +1 经验、鼠标点击 +2 经验
  • 等级经验条 + 升级光环与飘字
  • 本地存档 save.json，托盘菜单退出 / 重置
v0.2已交付
数值表与属性系统
把"数值"从代码里赶出去——全部交给 MySQL 风格的多表 Excel 配置。
  • Excel 数值表：8 张表（属性定义 / 品种 / 成长 / 招式 / 克制 / 状态 / 战斗常数 / 天赋）
  • 启动自动检测 Excel 改动并重新导出 JSON，策划改表即生效
  • 属性体系：核心（血 / 耐 / 攻 / 甲 / 速）+ 派生（耐力回复 / 暴击 / 韧性 / 破甲）+ 隐藏（斗性 / 体重 / 士气）
  • 品种配色由数值表主色直接生成——换品种即换外观，6 个品种已可区分
  • 护甲走百分比递减 ARM/(ARM+100)，速度走线性收益（快一倍＝打两倍次数）
  • 属性面板：实时数值、出手间隔、护甲减伤、天赋、战力评分
  • 存档升级：记录品种与天赋，兼容旧档
v0.3已交付
交互界面与设置
把蛐蛐从"能看"变成"能操作"——右键出功能菜单。
  • 右键蛐蛐弹出功能菜单：蛐蛐属性 / 蛐蛐设置 / 退出游戏
  • 蛐蛐设置面板：大小滑块（60%~200%，拖动即时预览）、显示经验条、始终置顶、品种预览
  • 属性面板加大头照：蛐蛐头像会呼吸眨眼（复用主程序动画状态）
  • 属性面板补上等级、经验条、还差多少升级、累计经验
  • 缩放系统：整个桌宠（蛐蛐+经验条+文字）等比缩放，会自动吸附回屏幕内
  • 设置与存档分离（data/settings.json），重置蛐蛐不会清掉外观偏好
v0.4下一版
状态条与喂食
给蛐蛐加上"要照顾"的需求，把挂机涨经验变成主动养蛐蛐。
  • 三条状态：饱食度 / 心情 / 体力，随时间自然衰减
  • 状态影响成长：心情 ≥80 时经验 +20%，饥饿时减半
  • 食物道具（表单新增「9-食物」表）：毛毛虫 / 豆类 / 露水，分品质与效果
  • 喂食动画与状态回复，经验作为通用货币
  • 训练小互动：连点 / 节奏点击，定向提升某一属性
v0.5待开始
斗蛐蛐对战 核心玩法
项目名字里的"斗"，玩法真正成立的一版。全部数值取自数值表。
  • 持续回复的耐力池：每秒回耐力，出手消耗；耐力见底才进力竭（受伤 +50%，1.5 秒后回满），把力竭做成战术节点而非空窗
  • 招式博弈：轻咬 / 冲撞 / 格挡 / 鸣叫 / 撕咬 / 摔投，克制矩阵做成石头剪刀布
  • 士气与逃跑：士气归零会逃跑判负——真实斗蛐蛐比的不是打死，是谁先怂；斗性决定士气下降速度
  • 护甲百分比减伤 + 破甲克制；暴击 / 韧性 / 闪避随机性
  • 状态系统：流血、破防、畏缩、士气高涨（表 6 已定义）
  • 战斗表现：冲撞、撕咬、鸣叫振翅（复用蛐蛐翅膀动画）、伤害飘字与血条
  • 双败北条件结算：血量归零 / 士气崩溃逃跑
  • 战斗加速与跳过；第二次建议做「突然死亡」防止双高甲僵持
战斗窗口形态待定：是在蛐蛐旁边弹一个小战场，还是单独开一个窗口。 倾向小战场贴着蛐蛐弹出，保持桌宠感。

事项说明
战斗窗口形态 小战场贴蛐蛐弹出 vs 独立窗口，v0.4 前需定夺
蛐蛐美术风格 当前为萌系圆滚卡通，若改写实斗虫风只需改 cricket.py
数值驱动改造 已全部走 Excel 数值表，代码内无硬编码战斗数值；改表重启即生效
数值平衡（待配） 当前成长曲线偏陡：Lv30 攻击是 Lv1 的 6.7 倍、出手快 2.4 倍，后期容易秒杀。 建议在「3-成长」表压平攻击增量、抬高护甲增量，或做 1000 场模拟跑胜率分布
挂机经验速度 打字即涨，满级太快。v0.3 引入状态衰减后需下调基础经验或提高升级需求
全局钩子权限 pynput 在管理员权限程序中可能收不到按键，属系统限制
注意：v0.2 已做好旧档兼容（缺 species_id/talents 会自动补默认值）。 v0.3 加入状态字段后，同样必须保留兼容逻辑，否则老档会直接崩。
