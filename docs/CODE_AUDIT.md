# 全项目检查与玩法模拟（2026-09-24）

检查范围：桌宠主程序、设置与品种、数值加载、战斗引擎、副本推进、竞技场、装备数据与界面、美术渲染、持久化及测试脚本。修改保留现有美术与界面工作，不调整 Excel 数值表。验证使用临时角色、背包、设置和副本存档。

## 已修复问题

| 问题 | 影响与修复 |
|---|---|
| JSON 直接覆盖且吞掉写入异常 | 角色、设置、背包、副本及数值导出统一原子写入；失败保留旧文件并向上报告错误。 |
| 数值重新加载失败清空已有数据 | 保留上一次有效配置；自动导出失败后使用旧 JSON 时保留错误信息。 |
| 退出没有完整收尾 | 统一关闭路径，保存当前副本血量、角色与挂机位置，停止计时器及输入钩子。 |
| 副本断点重新随机生成敌人 | 保存敌人名单和随机数状态；恢复校验层数、敌人索引和名单，兼容旧断点。 |
| 最终首领掉落被通关分支跳过 | 先结算掉落再通知通关；胜利动画中退出同样结算，重复退出不重复发奖。 |
| 旧通关延时回调关闭新副本 | 回调绑定完成的舞台，只退出对应战局；切换战局先保存旧舞台。 |
| 竞技场关闭仍继续战斗、最后难度重试状态错误 | 关闭停止计时器，重试创建新的副本流程；修正通关回调参数。 |
| 条件天赋和韧性没有生效 | 接入当前表内条件属性规则及抗暴计算；装备仍在下一场战斗生效。 |
| 反伤致死后继续攻击、结束后继续状态事件 | 致死反伤立即终止该次攻击，终局事件排在最后，表现层结束角力和冲刺。 |
| 成长表封顶后仍升级、重置未重算 | 等级以成长表为上限，封顶经验限制、经验需求保底；重置立即更新属性。 |
| 掉率为零被当作默认掉率、最高品质假升级 | 保留零掉率，仅使用有效正权重品质；存在下一品质才标记词条升档。 |
| 背包 UID 冲突、词条缓存过期 | 避开已有 UID；词条读取当前数值库，计算尊重传入数据库。 |
| 战斗中缩放导致窗口和遮罩错乱 | 战斗保持舞台尺寸和无遮罩，缩放设置回挂机后应用；属性面板战斗时继续刷新。 |
| 多屏面板越界、扩展难度按钮溢出 | 面板按所在屏幕可用区域定位，难度列表支持滚动。 |
| 测试可能污染玩家存档、复活测试偶发误报 | 增加公共临时存档隔离；复活测试直接制造实际致死事件，避免敌人先逃跑。截图脚本也隔离存档，使用 Qt 定时器退出。 |

此前品种重启不一致、KO 条块覆盖和触须根部脱离的回归一并保留。

## 验证边界

- Qt 使用离屏模式，真实窗口类、舞台、绘制与计时逻辑均参与测试；没有进行真人键鼠、系统托盘和多显示器实机逐项验收。
- 没有进行数小时实机挂机压力测试，也没有运行桌面截图脚本采集用户桌面。
- 原子写入保护单个文件；不是跨角色、装备、副本三个文件的事务，也不支持多个游戏进程同时修改同一存档。
- 工作区保留原有改动和玩家数据；此次未执行提交或推送。

## 补充：重置蛐蛐同步重置副本

重置现在清除副本断点、通关和解锁记录，下一次从新手第 1 层开始。先废弃桌面和竞技场的旧战局，取消待结算奖励，防止关闭窗口或延迟回调恢复旧进度；难度面板重新构建。保留品种、装备、位置和设置。新增两项回归覆盖选择面板、重新入场及结算动画期间重置。

## 补充：入场朝向

入场插值与普通战斗走位原先同时执行，导致位置及朝向被覆盖；副本增援还继承旧敌人的 KO 翻转、冲刺和击退。现在入场及休整帧独立控制位置，身体沿路径朝向前进；新敌人清理旧动作状态。两项新增回归逐帧检查竞技场双方、副本入场的移动方向与朝向，以及死亡后增援状态。

## 补充：清层提示与掉落反馈

清层返回 cleared_floor（已完成）和 floor（下一层），休整提示不再使用问号或提前声称休整完毕。装备入库成功后触发独立视觉队列：部位图标弹起、品质色光晕/环形粒子、飞入奖励卡，显示品质及已收入背包。单件动画 4.6 秒，连续掉落排队显示，位置取掉落瞬间快照，不随增援跳动。重置清空特效，不改变掉率或奖励次数。新增层数文案与视觉队列/过期/绘制回归。预览见 ui_loot_effects.png。
